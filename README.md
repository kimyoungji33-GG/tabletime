# 도란도란 TV

식사시간에 큰 버튼으로 고르는 세 채널: 어질리티·도그쇼, 세계 스포츠(축구·야구 하이라이트), 세계 풍경(Scenic Relaxation).

공개 홈페이지: https://tabletime-youngji.alightmink64.chatgpt.site/

## 사용

정적 HTML/CSS/JavaScript입니다. GitHub Pages에서 브랜치 루트를 배포할 수 있습니다. 재생목록은 약 60~90분을 목표로 구성하며 원본 영상은 끝까지 재생합니다. 시청 횟수만 브라우저에 저장하고 자동으로 영상을 제외하지 않습니다.

배경음악은 사용자가 선택한 YouTube 영상 두 개를 순서대로 반복합니다. 원래 영상과 배경음악은 소리를 각각 조절할 수 있습니다. 나라·경기 이름표는 사용자 요청으로 제거했습니다. 모든 채널에서 안 본 영상을 우선 추천하고, 전체 목록에서는 본 영상도 다시 선택할 수 있습니다.

## 제한

YouTube 영상·음원 파일은 포함하지 않습니다. 광고와 지역·외부 재생 제한이 있을 수 있습니다. 콘텐츠는 메타데이터로 확인한 후보이며 전체 장면 검수는 완료하지 않았습니다. 공식 홈페이지에는 새 영상 저장 서버를 배포했습니다. 예약 작업과 실제 갱신은 연결·검증 중입니다. GitHub의 정적 파일은 초기 영상 목록으로 작동하며, 최신 서버 전체 소스는 server-source.zip에 포함되어 있습니다. 서버에는 비밀 값 OWNER_EMAIL과 R2 BUCKET 연결이 필요합니다. 비밀 값은 저장소에 포함하지 않습니다.

Google 계정 정보나 비밀번호를 읽거나 저장하지 않습니다. 계정 선택 버튼은 Google의 공식 화면으로 연결됩니다. 외부 YouTube는 브라우저의 로그인 상태를 따릅니다.
